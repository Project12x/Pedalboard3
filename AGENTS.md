# AGENTS.md

## Repository Workflow

This is a single-developer repository. Do not create pull requests by default.

Default workflow:

1. Work on the requested branch or create a `codex/` feature branch when useful.
2. Commit focused changes locally.
3. Push the branch or `main` directly when the user asks to back up or publish work.
4. Merge feature branches to `main` locally when requested, then push `main` directly.

Only create a pull request if the user explicitly asks for one.

Closed historical PRs should not be treated as the normal process for this repo.

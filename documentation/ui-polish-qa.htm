Purpose

This checklist records visual evidence for Phase 6 UI polish work. Every polish milestone should include a filled copy of this page's matrix in the review notes, with screenshots stored beside the tested build or PR.

Required automated gate: run Pedalboard3_Tests [ui][regression] before closing a UI polish milestone.

Sign-off Criteria

  • Density: dense patches remain scannable without text or control overlap.
  • Contrast: labels, meters, pins, and critical controls are readable in every built-in theme.
  • Focus: keyboard focus and active controls are visible where applicable.
  • Scaling: layouts hold at 100%, 150%, and 200% DPI.
  • Stage readability: current patch, next patch, meters, and panic affordance are readable from performance distance.
  • Responsiveness: no visible UI lag from polish changes under normal and dense patch scenarios.
